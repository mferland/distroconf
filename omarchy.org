#+title: Omarchy workstation setup

* Restore the managed configuration

Install Omarchy from its official ISO, then follow [[file:README.md][the restore guide]]:

#+begin_src sh
git clone git@github.com:mferland/distroconf.git ~/dev/distroconf
~/dev/distroconf/bootstrap.sh
#+end_src

The bootstrap installs the package manifests and pinned shell plugins,
backs up conflicting files, links the managed dotfiles, installs the Emacs
user service, and restores the theme, font, and background. Hyprland input
and appearance use the Lua files under =dotfiles/.config/hypr/=. The shell
layout and clock format live under =dotfiles/.config/omarchy/=.

SSH uses Omarchy's native =ssh-agent.socket=. The managed Bash profile and
Emacs unit select its socket; no custom SSH-agent service is needed.

Use [[file:README.md][the VM testing workflow]] before applying configuration changes to a workstation.
For YubiKey enrollment and SSH connection reuse, see [[file:yubikey.org][the YubiKey guide]].

The sections below are optional machine-specific tasks. Bootstrap does not
apply them automatically.

* Keyboard firmware mapping

=70-keyboard.hwdb= maps a key on the matching USB keyboard to Left Meta.
Install it only on a workstation using that keyboard:

#+begin_src sh
sudo install -m 0644 ~/dev/distroconf/70-keyboard.hwdb /etc/udev/hwdb.d/70-keyboard.hwdb
sudo systemd-hwdb update
#+end_src

Reconnect the keyboard to apply the rule. The general US/Canadian layout and
Shift-key layout switching are already managed by =input.lua=.

* Optional RTags integration

The Emacs configuration includes RTags support. If you use it, install the
RTags tools separately and verify that =/usr/local/bin/rdm= exists before
installing these units:

#+begin_src sh
mkdir -p ~/.config/systemd/user
install -m 0644 ~/dev/distroconf/rdm.service ~/.config/systemd/user/rdm.service
install -m 0644 ~/dev/distroconf/rdm.socket ~/.config/systemd/user/rdm.socket
systemctl --user daemon-reload
systemctl --user enable --now rdm.socket
#+end_src

For kernel sources, generate a compilation database after configuring and
building the kernel, then index it:

#+begin_src sh
./scripts/clang-tools/gen_compile_commands.py
rc -J .
#+end_src

* Optional LanguageTool integration

Emacs is configured to contact LanguageTool on =localhost:8010=. If you use
this integration, install Docker through Omarchy and verify its service is
running before installing the container unit:

#+begin_src sh
omarchy install docker
sudo install -m 0644 ~/dev/distroconf/langtool.service /etc/systemd/system/langtool.service
sudo systemctl daemon-reload
sudo systemctl enable --now langtool.service
#+end_src

The service pulls the LanguageTool image on its first start.

* Optional network mounts

See [[file:mounts.org][the network mounts guide]] for location-aware NFS and CIFS setup.

=nfs-utils= is included in the package manifest. Configure workstation-specific
mounts separately in =/etc/fstab= or systemd mount units, using the correct
server, exported paths, and local mount points. These mappings are not portable
between workstations and are not managed by bootstrap.
