* Optional RTags integration

The Emacs configuration includes RTags support. If you use it, install the
RTags tools separately and verify that =/usr/local/bin/rdm= exists before
installing these units:

#+begin_src sh
mkdir -p ~/.config/systemd/user
install -m 0644 ~/dev/distroconf/rdm.service ~/.config/systemd/user/rdm.service
install -m 0644 ~/dev/distroconf/rdm.socket ~/.config/systemd/user/rdm.socket
systemctl --user daemon-reload
systemctl --user enable --now rdm.socket
#+end_src

For kernel sources, generate a compilation database after configuring and
building the kernel, then index it:

#+begin_src sh
./scripts/clang-tools/gen_compile_commands.py
rc -J .
#+end_src
